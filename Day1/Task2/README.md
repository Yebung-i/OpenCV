
## 자율주행과 로봇분야에서 Opencv가 어떻게 사용되는지 조사하라
- 차선의 인식 및 추적
- 보행자 및 사물 인식과 분류
- 사물과의 거리 측정
- 사물의 이동 속도와 방향 계산 등

## CLI 개발환경이 GUI 환경보다 장점을 조사하라
- GUI는 창을 띄우고 그래픽을 렌더링 하는 것에 RAM과 CPU 자원을 사용하지만, CLI는 텍스트만 처리하므로 가볍고 빠르다.
- GUI는 사람이 마우스로 버튼을 눌러야 하지만, CLI 명령어는 하나의 스크립트 파일 (`.sh`, `.bat`) 로 묶어 많은 작업을 자동화 하는 것이 가능하다.
- 네트워크 대역폭을 매우 적게 차지해 불안정하거나 느린 환경에서도 SSH등을 통해 원격서버에 접속하여 딜레이 없이 개발 및 제어가 가능하다.
- 파이프 기능을 통해 A명령어의 결과물을 B명령어의 입력물로 바로 전달할 수 있다.

## Numpy의 라이브러리가 파이썬 라이브러리 보다 빠른 이유를 설명하라
- NumPy의 내부 핵심 코드는 파이썬이 아니라 C언어로 작성되어 있기에, 파이썬처럼 실행할 때마다 코드를 해석 하는것이 아니라 미리 컴파일된 정적 코드가 실행되어 연산이 빠르다.
- 또한 파이썬의 리스트는 객체가 메모리 곳곳에 산개되어 저장되고 리스트에는 그 주소값만 들어있기에 오버헤드가 크지만, Numpy의 ndarray는 데이터가 메모리의 연속된 공간에 차례로 저장되고, 대용랴으이 데이터를 한 번에 CPU 캐시 메모리로 가져오기에 읽기 속도가 비약적으로 상승한다.
