## 영상처리, 컴퓨터 비전기술이 자율주행, 로봇분야에서 사용되는 사례를조사하시오
- 자율주행 : 카메라로 도로 영상을 촬영하여 영상처리 기술을 이용해 차선을 검출한다. 또한 컴퓨터 비전 알고리즘이 차선의 위치 및 곡률 등을 분석해 주행 경로를 결정하게 된다.

## CMOS 센서의 원리를 자세히 조사하시오
- 1단계 [빛 감지] : 빛이 센서 표면에 도달하면, 각 픽셀 내부에 있는 포토다이오드가 광자를 흡수하고, 반도체 내부에서 전자와 정공 쌍이 생성되는 광전효과가 발생한다. 이는 빛이 강할수록 더 많은 전자가 생성된다.

- 2단계 [전하 축적] : 생성된 전자들은 포토다이오드에 모이게 된다. 카메라의 셔터 속도(노출 시간) 동안 계속 쌓인다.

- 3단계 [전하 -> 전압 변환] : CMOS 센서에는 각 픽셀마다 자체 트랜지스터가 내장되어 있는데, 포토다이오드에 쌓은 전자(전하량)는 픽셀 내부의 트랜지스터를 통해 전압 신호로 변환되어 출력된다.

- 4단계 [아날로그 -> 디지털 변환] : 픽셀에서 출력된 아날로그 전압 신호는 주변부의 ADC(아날로그 디지털 변환기) 를 거쳐 0과 1로 이루어진 디지털 데이터로 변환된다. 해당 데이터가 ISP로 넘어가 우리가 보는 사진이 된다.

##  아날로그 신호를 디지털 신호로 변환하는 과정에서 샘플링과 양자화의 차이를 설명하시오.
- 표본화(샘플링) : 우리가 눈으로 보는 세상은 (빛) 무한하고 연속된 값을 가지지만, 카메라를 통해 컴퓨터로 저장되는 빛은 무한할 수 없기에 (용량이 제한되어 있기에) 일정한 위치에서만 측정하여 유한한 화소의 수만큼 입력 값을 가지게 된다.
- 양자화 : 디지털 카메라 등에서 제한된 비트 크기로 화소값을 나타내기 위해서는 그 밝기 값을 모두 나타낼 수 없다. 예를 들어 표본화된 화소값이 128.345... 라고 하였을때, 8비트 디지털 화소로 나타내는 경우에는 128로만 나타내는 식이다.

- 차이점: 결론적으로는, 샘플링은 연속된 빛의 데이터에서 어느 순간(When)의 데이터를 가져올건지, 양자화는 추출한 데이터의 크기를 얼마로(What) 기록할 것인지를 의미한다.

##  영상의 해상도의 정의와 이미지 센서의 개수의 관계를 설명하시오
- 해상도 : 화면을 구성하는 픽셀(화소)가 가로와 세로에 각각 몇 개씩 포함되는지를 의미한다. 즉, 1920x1080 해상도는 픽셀이 가로 1920개, 세로 1080개가 있다는 의미이다.
- 이미지 센서(CMOS) 는 들어오는 빛을 0과 1의 전기 신호로 바꿔주는 반도체 칩으로서, 수많은 픽셀로 이루어져 있다. 즉, 이미지 센서의 소자 개수가 많아진다면, 픽셀(화소) 수가 증가하므로 해상도가 증가한다.

## 200X100 그레이스케일 영상 파일의 크기(바이트)를 계산하라.
- 20,000 Byte 이다.
 
## 200X100 컬러 영상 파일의 크기(바이트)를 계산하라.
- 20,000 * 3 = 60,000 Byte 이다.
