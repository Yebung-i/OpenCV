
## 다음 용어를 설명하라.
### 단위행렬(identity)
- 주대각선의 성분이 모두 1이고, 나머지 성분은 모두 0인 정사각행렬

### 역행렬(inverse)
- 임의의 정사각행렬 A를 곱했을 때 단위행렬 I가 되게 하는 행렬 (역수의 개념)

### 전치행렬(transpose)
- 임의의 행렬의 행과 열을 서로 맞바꾼 행렬

## 파이썬 리스트와 넘파이 ndarray의 데이터 저장방식을 비교하고 넘파이가 처리속도가 빠른 이유를 설명하라
- 파이썬 리스트 : 각 요소에 대한 참조를 저장함, 서로 다른 자료형을 함께 저장할 수 있으며, 실제 데이터는 메모리 곳곳에 흩어져 있다.
- 넘파이 : 동일한 자료형의 데이터를 사용하며 데이터를 메모리에 연속적으로 저장한다.

### 넘파이가 빠른 이유
- 파이썬의 리스트는 객체가 메모리 곳곳에 흩어져 있고, 참조를 저장하기 때문에 값을 가져올 때 오버헤드가 크지만, 넘파이는 메모리의 연속된 공간에 차례로 저장되고, 대용량의 데이터를 한 번에 CPU 캐시 메모리로 가져오기에 읽기 속도가 빠르다.
